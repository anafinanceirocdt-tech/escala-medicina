# Escala Medicina 5x2

Plataforma de escalas por setor: recepção, pós-médico, biomédicas, limpeza, odontologia e call center.

## Publicação

Adicione `index.html` na raiz deste repositório. Na Vercel, importe o repositório como projeto estático (Framework Preset: Other).

**Atenção:** o protótipo atual usa localStorage. Não há autenticação nem sincronização entre dispositivos; não publique dados pessoais reais antes de implementar controle de acesso e Supabase.
